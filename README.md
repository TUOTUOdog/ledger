# 随手记 · v1（手动记账版）

一个只存在你自己设备上的记账网页。没有账号、没有服务器、不联网上传。

> **2026-11-24 更新：公司网络把有线和无线隔离了，手机连不上这台电脑。**
> 推荐改走免费静态托管（第六节），手机用 4G 也能开，而且电脑不用开机。
> 第一节的局域网方式只在你自己的路由器/热点下才管用。

## 一、怎么在手机上打开

1. 手机连上**和电脑同一个 Wi-Fi**。
2. 手机浏览器（Chrome / Edge / 夸克都行）打开：

   **http://192.168.119.115:8000/**

3. 打开后点浏览器菜单 →「添加到主屏幕」，以后就像 App 一样点开。

> 电脑必须开机、并且这个服务在跑，手机才打得开。
> 服务由我这次启动的后台任务提供；电脑重启后需要重新启动（见第四节）。

### 打不开怎么办

- **确认同一个 Wi-Fi**：手机要连家用 Wi-Fi，不能是移动数据。
- **电脑上可能弹了防火墙提示**：去电脑右下角看有没有「是否允许访问」，点**允许**（勾选"专用网络"）。
- 还是没有？用**管理员身份**开一个 PowerShell，粘这行：

  ```powershell
  New-NetFirewallRule -DisplayName "LedgerDev 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
  ```

## 二、它能干什么

| 功能 | 说明 |
|---|---|
| 记一笔 | 填金额 → 会自动推荐分类 → 写备注 → 保存 |
| 自动归类 | 输入"瑞幸"自动跳到「餐饮」，输入"滴滴"自动跳到「交通」 |
| 记住你的习惯 | 你手动改过的分类，下次同一商户直接沿用 |
| 明细 | 按月看，按天分组，点任意一条可以改金额/分类/备注或删除 |
| 待补备注 | 明细里筛「待补备注」，专门补没写备注的账 |
| 统计 | 本月支出/收入/结余 + 分类排行 |
| 备份 | 导出 JSON（完整）/ CSV（可用 Excel 打开），也能合并导入回来 |

## 三、数据存在哪（很重要）

存在**手机浏览器的本地存储**里，不在电脑上，也没上云。

所以：

- **清除浏览器数据 = 数据全没**。别在浏览器设置里点"清除网站数据"。
- 换手机、换浏览器、换 IP 地址，都会看不到旧数据。
- **每周导出一次 JSON 备份**（更多 → 导出备份），存到微信收藏或网盘。

## 四、电脑重启后怎么重新启动

在 PowerShell 里跑：

```powershell
& "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" -m http.server 8000 --bind 0.0.0.0 --directory "$env:USERPROFILE\Documents\deepseek-harness\default-workspace\ledger"
```

窗口别关，关了服务就停了。

## 六、放到互联网上（推荐，一劳永逸）

公司网络隔离，局域网走不通。把下面 5 个文件传到免费的 GitHub Pages，手机用 4G 也能开，
电脑不用开机：

```
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
```

步骤：

1. 打开 github.com，注册 / 登录。
2. 右上角 `+` → **New repository** → 名字填 `ledger` → 选 **Public** → Create。
3. 仓库首页点 **uploading an existing file**，把上面 5 个文件全选拖进去 → **Commit changes**。
4. **Settings** → 左侧 **Pages** → Source 选 *Deploy from a branch* → Branch 选 `main` / `/ (root)` → Save。
5. 等 1~2 分钟，访问 `https://你的用户名.github.io/ledger/`。

装到手机：用手机浏览器打开这个地址 → 菜单 →「安装应用」或「添加到主屏幕」。
之后有独立图标、断网也能记（Service Worker 已缓存）。

**仓库是公开的，但里面只有代码，没有任何账目数据**——数据一直在你手机浏览器里。

换地址（比如从 192.168.x.x 换到 github.io）后，旧数据不会跟过来。
先到「更多 → 导出备份」，新地址打开后再「从备份恢复」。

如果 github.io 打不开，同样的 5 个文件可以拖到 **Cloudflare Pages**（免费，直接上传无需 git）。
